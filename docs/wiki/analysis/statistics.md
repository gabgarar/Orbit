# Estadísticas

[Análisis](index.md){ .md-button }

Orbit no ofrece un módulo de estadísticas orbitales, agregación de flotas ni
comparación estadística de trayectorias. Las tablas de catálogo, los filtros y
los metadatos de objetos sirven para organizar datos operativos, pero no
constituyen un motor de métricas científicas.

## Estado

**No disponible:** distribución de errores, percentiles de cobertura,
estadísticas de revisita, agregación de eventos, análisis de población,
correlación de trayectorias y exportación de informes estadísticos.

## Uso de datos disponibles

Los datos exportados por Orbit pueden analizarse en una herramienta externa si
el operador conserva el contrato de marco, escala temporal, unidades y modelo
de propagación. Las conclusiones estadísticas obtenidas fuera de Orbit no se
atribuyen al producto ni se reimportan como un resultado validado.
