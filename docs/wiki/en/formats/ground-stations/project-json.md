[Home](../../index.md) · [Ground-station formats](index.md)

## Current contract

Stations are serialized inside the project JSON document. The state includes
name, latitude, longitude, altitude, elevation mask, radio parameters, and
visual or coverage options.

## Scope

This JSON is an internal workspace format, not an interchange standard.
Compatibility is defined by the Orbit project that produced it, not by a
public station specification.

See [Ground stations](../../user-guide/ground-stations.md) for fields and
visibility calculation.
