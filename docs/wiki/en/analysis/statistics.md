# Statistics

[Analysis](index.md){ .md-button }

Orbit does not offer an orbital statistics module, fleet aggregation or
statistical comparison of trajectories. Catalog tables, filters, and
Object metadata is used to organize operational data, but not
They constitute an engine of scientific metrics.

## Status

**Not available:** error distribution, coverage percentiles,
revisit statistics, event aggregation, population analysis,
Correlation of trajectories and export of statistical reports.

## Usage of available data

Data exported by Orbit can be analyzed in an external tool if
the operator retains the framework contract, time scale, units and model
of propagation. Statistical conclusions obtained outside of Orbit are not
attributed to the product or reimported as a validated result.
