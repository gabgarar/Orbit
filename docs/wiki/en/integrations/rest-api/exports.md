# REST API: export

[Integrations](../index.md) · [REST API](../rest-api.md) · [Formats](../../formats/index.md)

| Method and route | Product |
| --- | --- |
| `GET /api/export/tle/:satId` | TLE file of a TLE source entry. |
| `GET /api/export/omm/:satId?format=json\|xml` | OMM JSON or XML from an OMM source entry. |
| `GET /api/export/oem/:satId` | Simplified OEM header from an OEM source entry. |
| `GET /api/export/ocm/:satId` | OCM JSON simplified. |
| `GET /api/export/ephemeris/:satId?t0=…&t1=…` | SGP4 anniversary in `csv`, `json` or `oem`; `dt` > 0 and ≤ 3600 s. |

Catalog exports verify that the requested format corresponds
to the origin when applicable. OMM, OCM and OEM generated by Orbit do not declare
Complete coverage of all profiles of your standards.

## Ground stations

Ground-station interchange is not a REST endpoint. The application imports and
generates GeoJSON RFC 7946, Orbit JSON, and CSV locally from authored
station-layer contracts. GeoJSON downloads as <code>application/geo+json</code>,
Orbit JSON as <code>application/json</code>, and CSV as <code>text/csv</code>.

Those operations do not call this API or turn an AOS/LOS response into an
interchange file. See [Ground-station interchange](../../formats/ground-stations/interchange.md)
for the schema, local validation, and limits.
