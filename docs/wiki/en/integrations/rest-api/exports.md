# REST API: export

[Integrations](../index.md) · [REST API](../rest-api.md) · [Formats](../../formats/index.md)

Export routes distinguish a retained source, a reduced product derived from a
catalog entry, and a calculated ephemeris. A route must not be used to present
a derived document as though it were the imported CCSDS file.

## Catalog products

| Method and route | Product and boundary |
| --- | --- |
| `GET /api/export/tle/:satId` | The two lines of an entry whose actual source is TLE. It rejects other provenance and incomplete lines. |
| `GET /api/export/omm/:satId?format=json\|xml` | OMM JSON/XML **derived from the catalog entry** when its provenance is OMM. It is a normalized, reduced profile, not the raw file or a byte-for-byte copy. |
| `GET /api/export/oem/:satId` | A legacy compatibility route for a reduced derived profile. It does not provide the source OEM samples or metadata and must not be consumed as a usable ephemeris OEM. It is not offered as a UI action. |
| `GET /api/export/ocm/:satId` | Simplified OCM JSON generated by Orbit, not full standards coverage. |

The routes validate catalog provenance. The optional `sourceFormat` parameter of
a sampled export cannot override it: a mismatch with retained provenance returns
`400`.

## Sampled ephemerides

| Method and route | Product |
| --- | --- |
| `GET /api/export/ephemeris/:satId?t0=…&t1=…&dt=…&format=…` | An ephemeris for a TLE or OMM catalog entry using SGP4. `dt` must be greater than 0 and less than or equal to 3600 seconds. |
| `POST /api/export/manual-ephemeris?format=…` | An ephemeris for a manual definition using the same propagator, integrator, and force model in the `ManualOrbitRequest`. It never creates a synthetic TLE. |

`csv`, `json`, and `oem` return Cartesian samples or a serialization of them.
Accepted geospatial formats are `geojson`, `kml`, `kmz`, `gpkg`, `wkt`, and
`wkb`; they require terrestrial ITRF/ITRS/WGS-84 samples. A request attempting
to run SGP4 over an OEM-source entry receives `409`: Orbit does not relabel that
OEM or apply a propagator unrelated to its samples.

| `format` | Extension | `Content-Type` | Orbital geometry |
| --- | --- | --- | --- |
| `geojson` | `.geojson` | `application/geo+json` | 2D `LineString` ground track. |
| `kml` | `.kml` | `application/vnd.google-earth.kml+xml` | 3D `LineString` track with ellipsoidal height. |
| `kmz` | `.kmz` | `application/vnd.google-earth.kmz` | Compressed 3D KML. |
| `gpkg` | `.gpkg` | `application/geopackage+sqlite3` | `LineString Z` in EPSG:4979. |
| `wkt` | `.wkt` | `text/plain` | Textual 2D `LineString` geometry. |
| `wkb` | `.wkb` | `application/vnd.ogc.wkb` | Binary 2D `LineString` geometry. |

### Anti-meridian crossings

When a track crosses between `+180°` and `-180°`, the API splits it into
`LineString` segments. This prevents a false chord through the map. GeoJSON
contains one `Feature` per segment; KML/KMZ one `Placemark` per segment;
GeoPackage one `LineString Z` feature per segment; and WKT/WKB a collection of
2D geometries when more than one segment is needed. The boundary point is
interpolated only for interchange: it is not a propagated sample and has no new
epoch.

KML/KMZ and GeoPackage heights are WGS-84 ellipsoidal. KML marks the path as
`absolute`; a viewer using another vertical datum, including Google Earth, can
show a visual offset relative to its geoid. Current orbital GeoJSON, WKT, and
WKB geometries omit altitude.

## Ground stations

The browser creates GeoJSON RFC 7946, KML, KMZ, WKT, WKB, Orbit JSON, and CSV
locally from every station layer's authored contract. GeoJSON, Orbit JSON, and
CSV are the only station formats accepted for re-import. KML/KMZ, WKT, and WKB
are export-only spatial representations.

| Method and route | Product |
| --- | --- |
| `POST /api/ground-stations/export` | A real GeoPackage (`format: "gpkg"`) containing WGS-84 Point Z features in EPSG:4979. |

The request contains `format` and a sanitized `stations` array. Before sending
it, the client removes Cesium entities, coverage meshes, RF caches, pass
results, and every other runtime-only value. The binary endpoint returns
`application/geopackage+sqlite3` and a download filename. It does not create
TLE, OEM, ephemeris, or derived coverage data.

See [Ground-station interchange](../../formats/ground-stations/interchange.md)
for the schema, local validation, and format boundaries.
