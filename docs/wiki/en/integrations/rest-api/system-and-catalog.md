# REST API: status, configuration and catalog

[Integrations](../index.md) · [REST API](../rest-api.md) · [OpenAPI](../openapi.md)

## Status and settings

| Method and route | Operation | Answer or main restrictions |
| --- | --- | --- |
| `GET /health` | Python gateway and backend status. | `200` with both states `ok`; `503` while the backend is unavailable. |
| `POST /api/system-config` | A healthy configuration persists and requests a backend reload. | Requires `system`; does not allow hot swapping of the active catalog. May return `503` after persisting if reload fails. |
| `GET /docs` | FastAPI Swagger UI through gateway. | See [OpenAPI](../openapi.md). |
| `GET /openapi.json` | OpenAPI description generated by FastAPI. | It does not have an independent public version. |
| `GET /redoc` | FastAPI ReDoc through the gateway. | Available as long as the backend is healthy. |

## Catalog

| Method and route | Operation | Parameters or body |
| --- | --- | --- |
| `GET /api/catalog/page` | Leaked local catalog page. | `offset` (≥ 0), `limit` (1–1000), `search`, `orbitKind`, `mission`, `operator`, `owner`, `decayOnly`, `sourceFormat` and `sourceOrigin`. |
| `GET /api/catalog/tle?name=…` | Searches for an entry by standard name. | `name` is required; responds `404` if it does not exist. |
| `POST /api/catalog/import` | Import textual catalog content. | `{ "fileName": "…", "content": "…", "merge": true }`; must produce valid TLEs. |
| `POST /api/catalog/refresh` | Updates configured remote sources. | `?discover=true` requests discovery; It is disabled offline, limited to one attempt every two hours, and no concurrent refreshes. |

`/api/catalog/page` returns `items`, `total`, `offset`, `limit`, `hasMore`,
auxiliary filters and the perigee decay threshold. `catalogId` is done
unique when there are duplicate names; should not be replaced by the original name
when building a UI selection.
