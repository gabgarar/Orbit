## Contrato actual

Las estaciones se serializan dentro del documento JSON del proyecto. El estado
incluye nombre, latitud, longitud, altitud, máscara de elevación, parámetros
de radio y opciones visuales o de cobertura.

## Alcance

Este JSON es un formato interno de espacio de trabajo, no un estándar de
intercambio. La compatibilidad se define por el proyecto Orbit que lo produjo,
no por una especificación pública de estación.

Consulte [Estaciones de tierra](../../user-guide/ground-stations.md) para los
campos y el cálculo de visibilidad.
